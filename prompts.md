## New Feature

```
You are a senior .NET backend engineer.

Requirement:

- [Describe the feature]

Project Context:

- ASP.NET Core Web API
- Vertical Slice Architecture (VSA)
- CQRS with MediatR
- Entity Framework Core
- FluentValidation
- Clean, readable, maintainable code
- Existing project conventions must be followed

Requirements:

- Generate only the necessary files/classes.
- Reuse existing abstractions and extension methods where appropriate.
- Do not introduce unnecessary patterns or libraries.
- Keep business logic inside the appropriate layer.
- Use async/await where applicable.
- Add brief comments only where the logic is non-obvious.
- If any requirement is ambiguous, state the assumption before generating code.
```
