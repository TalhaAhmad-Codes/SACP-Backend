# Theme Codes

## General

**Primary Colors**
- Main Brand Color `#2563EB`
- Hover State `#1D4ED8`
- Light Background `#DBEAFE`

**Secondary Color**
- Accents `#7C3AED`
- Light Backgorund `#EDE9FE`

**Background Surface**
- Page background - `#F8FAFC`
- Card background - `#FFFFFF`
- Input background - `#F1F5F9`
- Border Color - `#E2E8F0`

**Status Colors**
- Active / Success - `#16A34A`
- Warning / Medium Priority - `#D97706`
- Critical / Urgent / High Priority - `#DC2626`
- Inactive / Low Priority - `#6B7280`

**Text Color**
- Heading - `#0F172A`
- Body - `#334155`
- Muted / Labels - `#64748B`
- Placeholders - `#94A3B8`

## Font & Spacing

**Font Size**
> Google Fonts
- Heading 1 - `Inter(600)`
- Heading 2 - `Inter(500)`
- Heading 3 - `Inter(400)`
- Font - `Segeo UI`

**Page - Font Size**
- Title - `24px` *Bold*
- Section-Title - `18px` *Bold*
- Card-Title - `16px` *Semi Bold*
- Body Heading - `14px` *Semi Bold*
- Body Text - `12px` *Normal*
- Label / Meta - `11px` *Medium*
- Badge - `10px` *Medium*

**Spacing**
- Page padding      - `p-6`
- Section gap       - `space-y-6`
- Card inner gap    - `space-y-4`
- Form field gap    - `space-y-3`
- Inline gap        - `gap-2` or `gap-3`
- Table cell        - `px-4` `py-3`

## CSS Hints

**Sidebar Layout**
- Width open        - `256px` *(w-64)*
- Width collapsed   - `64px`  *(w-16)*
- Background        - `#FFFFFF`
- Border right      - `border-r` `border-slate-200`
- Active item       - `bg-blue-50` `text-blue-600` `border-blue-100`
- Inactive item     - `text-slate-500` `hover:bg-slate-50`
- Icon size         - `w-5` `h-5`
- Transition        - `duration-300` `ease-in-out`

**Badges**
- Active    - `bg-green-100`  `text-green-700`  `border-green-200`
- Warning   - `bg-amber-100`  `text-amber-700`  `border-amber-200`
- Critical  - `bg-red-100`    `text-red-700`    `border-red-200`
- Info      - `bg-blue-100`   `text-blue-700`   `border-blue-200`
- Inactive  - `bg-slate-100`  `text-slate-500`  `border-slate-200`
- Style - `text-xs` `px-2.5` `py-0.5` `rounded-full` `border font-medium`

**Table Style**
- Header row  - `bg-slate-50` `text-slate-500` `text-xs uppercase`
- Body rows   - `bg-white` `hover:bg-slate-50` `transition`
- Divider     - `divide-y` `divide-slate-100`
- Cell        - `px-4` `py-3` `text-sm`

**Notification**
- Urgent  - `bg-red-100`    `text-red-700`
- High    - `bg-amber-100`  `text-amber-700`

**Shadows**
